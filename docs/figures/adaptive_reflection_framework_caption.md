## 图一：整体框架

**英文图题：Adaptive reflection for mathematical reasoning**

建议中文图注：数学自适应反思的离线监督与在线预算选择。离线为同一题建立 Direct、
一轮反思与两轮反思候选，标准答案仅用于候选评分。在线先生成初始回答，策略根据问题
与该回答选择动作；Direct 绕过反思器，其余动作按预定轮数执行修订。基础模型与反思器
均冻结，同一个反思器符号出现多次表示重复调用，不是多个独立训练模型。

### A. 离线监督从哪里来

1. 输入数学问题 `q`。Base 只看到问题和必要答案格式，不看到标准答案 `g`。
2. 冻结的 Base 生成初始响应 `y0`，该响应直接组成 D 候选。
3. 反思器读取 `q, y0` 得到 `y1`，再读取 `q, y1` 得到 `y2`。
4. 离线将抽取答案与 `g` 比较，计算正确性 `Ca`；累计相应路径的输入、输出及重试成本 `Ta`。
5. 主标签采用字典序 `argmax(Ca, -Ta)`：先尽量答对，再在同正确性下选择低成本路径。
6. 最优动作是否为 D 构成 Gate 标签；R1/R2 中的最优选择构成 Round 标签。

图中的账目表只展示符号，没有虚构样本得分。Gold 参与监督，不进入模型输入。
标准答案对齐使用数学评分，不使用词级 F1。

### B. 部署时如何走路径

新问题先获得 `y0`，编码器读取 `(q, y0)` 并提取向量。Gate 的 Direct 分数达到
验证集确定的门限时直接返回 `y0`，不调用反思器；否则 Round 选择 R1 或 R2。

Round 只看到原始状态，在反思调用前决定轮数。它不读取第一轮新答案再决定是否继续。
图中 R1 路径返回 `y1`，R2 路径返回 `y2`，不能借助测试标准答案回选更好的中间结果。
没有 QA Ranker、调用后候选采纳或在线 LLM verifier。

为使时序清晰，图中 Gate 和 Round 顺序排列；这并不表示把 Gate 的输出向量当作 Round
的文本输入。两者使用同一初始文本表示，各有独立参数和标准化统计量。

### 成本和长度边界

每条实际路径只计算一次 Base 成本，反思重复传入的文本作为新的输入 token 计费。
所有有 usage 的重试成本都要累加。输出保护不能保证模型永不触限，而是保证未解决的
截断不混入完整结果：超过固定恢复上限就停止并记录失败，不静默过滤题目。

## 图二：策略选择器网络

**英文图题：Inside the hierarchical policy selector**

建议中文图注：数学分层策略的文本表示与独立分类头。问题及初始响应经过完全冻结的
Qwen3-0.6B-Base，读取最后两层并进行 masked mean 与 last-valid-token 池化，拼接
为 4096 维表示。Gate 与 Round 分别经过训练侧拟合的 scaler 和 MLP，输出两个动作
logits。梯度只更新分类头，不回传编码器。张量颜色和神经元数量均为结构示意。

### 输入与编码器

- 输入是 `Question: ... Initial answer: ...` 的文本，不是人工正确性、难度或置信度。
- 本地编码器配置为 28 个 Transformer block，hidden size 为 1024。
- 当前实现以 `model.eval()`、`torch.no_grad()` 提取表示，优化器只接收 MLP 参数。
- **全部编码器层均不更新。高亮最后两层表示“被读取”，不表示“被微调”。**
- 最后一个隐藏状态包括模型最终归一化的影响，归一化参数同样不训练。
- 不使用词表 LM head 生成动作字符串，而是读取隐藏状态进行分类。

图上层堆叠由下到上为 Embedding、Block 1、压缩显示的中间层、Block 26、27、28。
省略号表示中间层仍参与前向，并不是删除或跳过这些层。

### 池化与拼接

每个选中层有 `L × 1024` 的隐藏状态矩阵：

1. `masked mean` 对所有有效 token 位置取均值，排除 padding。
2. `last valid token` 取最后一个有效位置的隐藏状态，而不是 padding。
3. 每种池化得到 1024 维。两层、两种池化合为四段，总计 4096 维。
4. 代码顺序为 `[mean(-2), last(-2), mean(-1), last(-1)]`。

图中的汇合括号表示收集四个向量后按上述顺序拼接，不是相加或注意力操作。
颜色只是帮助辨别层的来源，不是实测激活、置信度或重要性。

mean 与 last 分别提供位置聚合及末位置上下文表示，这是可通过消融检验的选择，
不是它们一定能识别推理错误的证明。7473 个样本与 4096 维之间不存在“应当相等”的关系。

### 两个分类头如何学习

Gate 与 Round 各自使用一个 StandardScaler，仅在该头的训练部分拟合。
MLP 均为 `4096 → 64 → 16 → 2`：两个隐藏层使用 ReLU，末层输出 logits。
经 softmax 后得到动作分数，而非已校准的答案正确概率。

- Gate：学习 D / reflect；主脚本不做类别加权。
- Round：学习 R1 / R2；主脚本依据训练频数加权。
- 每个头用交叉熵独立训练；每头 263282 个可训练参数，共 526564 个。
- 这不包含冻结编码器，也不包含通过非梯度方式拟合的 scaler 统计量。
- “不用手工特征”不等于“无标签训练”；Gold 自动产生监督标签，但不当输入。

图中每列只画少量神经元以保持可读性，真实层宽由下方数字标注。红色梯度箭头在
冻结边界处停止，不能解读为对最后两层做 LoRA 或端到端微调。

### 为什么这样选择

采用 Gate/Round 是把“需要额外计算吗”和“需要一轮还是两轮”分开学习，便于分别检查
误触发、漏修复和过度反思。它并不保证优于平坦三分类，必须保留相同数据和表示下的
三分类对照。最终要比较回答准确率、成本和修复/引错，而不只比较动作标签准确率。

部署先判 `p(D) >= threshold`；只有选择反思才使用 Round 的 R1/R2 分数。
门限和检查点应在训练侧共同验证集上锁定，不能反复看测试 Oracle 再调。

### epoch 与当前实现限制

历史三种子 Gate/Round 检查点分别为 seed 7: 1/1，seed 21: 1/5，seed 42: 1/2，
每次共训练 10 epoch，以首次最高验证答案准确率选择。真实曲线放在论文附录，不在
网络图里合成一条“理想训练曲线”。

历史 Gate 的最优反思代理指标不是端到端结果；正式确认还需要两头共享问题级验证
清单。当前编码长度为 1024 且可能裁剪文本，它与生成长度保护不同。需要单独审计
编码截断比例，不能声称整个框架从输入到输出都无截断。
